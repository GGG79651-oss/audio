Развёртывание аудиосервиса

Браузер студента записывает речь, локальный сервер распознаёт её и считает метрики, организатор выгружает CSV или отчёт за день. Здесь описано устройство сервиса, порядок запуска и то, что стоит проверить до занятия. Команды приводятся для Windows; варианты для macOS и Linux даны рядом.

Как это выглядит

Два экрана, больше в сервисе ничего нет. Оба сделаны на ванильном HTML и JS, без сборки и без внешних библиотек.

Страница студента

Единственное поле ввода — четырёхзначный ID. Дальше таймер с автостопом на пяти минутах, индикатор громкости (сразу видно, что микрофон пишет) и одна кнопка. После остановки показывается длительность и кнопка «Отправить ответ»: прослушивания и перезаписи нет, о чём предупреждает жёлтая врезка сверху.

Доска организатора

Всё управление на одной странице: счётчики по статусам, сборка отчёта за день, фильтры, выгрузка CSV и таблица ответов с метриками. Статусы обновляются сами каждые пять секунд, поэтому за ходом занятия можно следить не трогая страницу.

Архитектура и поток данных

Одна машина работает сервером, остальные — обычные браузеры. На устройства студентов ничего не ставится, файлы после занятия собирать не нужно.

Студент открывает страницу, вводит четырёхзначный ID и записывает ответ: MediaRecorder в браузере пишет Opus в контейнер webm. По кнопке «Отправить» файл уходит на сервер обычным multipart-запросом, сервер сразу отвечает 201 и кладёт запись в очередь — студент не ждёт.

Фоновый поток берёт задачи из очереди по одной: декодирует аудио через PyAV, прогоняет через локальный Whisper с таймкодами слов, считает метрики и пишет результат в SQLite. Очередь восстанавливается из базы при старте, поэтому перезапуск сервиса не теряет необработанные записи.

Локальный запуск на одной машине

Сервер и браузер на одном компьютере. Микрофон работает без сертификата: localhost браузер считает защищённым адресом.

Что нужно поставить заранее

Python 3.11 или новее с сайта python.org. При установке обязательно отметьте галочку «Add Python to PATH» — без неё скрипт запуска не найдёт интерпретатор. Больше ничего ставить не нужно: ffmpeg и openssl приносят с собой зависимости проекта.

Windows · командная строка из папки проекта
cd %USERPROFILE%\Desktop\Audio

rem создаст окружение, поставит зависимости и запустит сервис
run.bat

Файл run.bat можно и просто открыть двойным щелчком из проводника. Окно консоли нужно оставить открытым: пока оно закрыто, сервис не работает. Остановка — Ctrl+C в этом окне.

macOS и Linux · терминал из папки проекта
cd ~/Desktop/Audio
./run.sh

Окружение и зависимости ставятся один раз, дальше запуск занимает секунды. Скрипт сам печатает адреса, по которым сервис доступен, — IP определяется автоматически. После строки модель готова можно открывать:

АдресЧто там
http://localhost:8000/Страница студента: ID, запись, отправка
http://localhost:8000/adminПанель: таблица, CSV, отчёт за день
http://localhost:8000/healthПроба живости и длина очереди
Модель скачивается один раз

При первом распознавании подтянется small (~464 МБ) в кэш ~/.cache/huggingface. Чтобы не ждать на первой записи, прогрейте заранее — на Windows это .venv\Scripts\python -c "from faster_whisper import WhisperModel; WhisperModel('small', compute_type='int8')", на macOS и Linux тот же вызов через .venv/bin/python.

Сообщение address already in use означает, что сервис уже запущен в другом окне. Найти и снять процесс:

Освободить порт 8000

# macOS и Linux
pkill -f "uvicorn app.main:app"

Проверить без модели

Чтобы прогнать интерфейс, очередь и выгрузку CSV, не дожидаясь распознавания, поставьте в .env заглушку — она отдаёт фиксированный текст мгновенно:

.env

Режим на группу: все на одно устройство

Тот же сервис, доступный по сети. Отличие одно: обязательный https.

Микрофон и https

Браузеры выдают микрофон только в защищённом контексте. По адресу http://192.168.x.x кнопка записи не сработает — это политика браузера, а не сервиса. Исключение одно: localhost. Поэтому по сети сервис запускается только по https.

Сервер для группы
rem Windows — сам выпустит сертификат на текущий IP
run.bat --https

# macOS и Linux
./run.sh --https

Студенты:              https://10.24.2.252:8000/
Организатор:         https://10.24.2.252:8000/admin
Брандмауэр Windows спросит один раз — и это легко пропустить

При первом запуске сервиса Windows покажет окно «Разрешить обмен данными». Нужно поставить галочку «Частные сети» и нажать «Разрешить доступ». Если окно закрыть или отклонить, сервис будет работать, но с других устройств не откроется — и это выглядит точно так же, как изоляция клиентов. Поправить потом: Панель управления → Брандмауэр Защитника Windows → Разрешение взаимодействия с приложением → найти Python и включить «Частные».

Сертификат самоподписанный, поэтому при первом заходе браузер покажет предупреждение: «Дополнительно» → «Перейти». Один раз на устройство. Выпускает его scripts/make_cert.py — кроссплатформенно, средствами Python, системный openssl не нужен. В сертификат попадают текущий IP, localhost и имя хоста, поэтому при смене сети его нужно перевыпустить: удалить папку certs/ и запустить снова.

Нагрузка

Запись идёт в Opus 64 кбит/с — около 2,4 МБ на пятиминутный ответ (замерено: 118 КБ на 15 секунд). Группа в 45 человек — примерно 110 МБ суммарно, и то не одновременно. Узкое место не сеть, а распознавание: ≈8× быстрее реального времени на модели small с int8 на Apple Silicon. 250 минут аудио обрабатываются примерно за полчаса, фоном.

Разогнать можно параметром ASR_WORKERS (2–3, упирается в ядра) или моделью base. Точнее — medium, но время растёт примерно втрое.

Проверка перед занятием

  1. Открывается ли напечатанный адрес с чужого устройства, а не только с сервера.
  2. Даёт ли браузер студента доступ к микрофону после принятия сертификата.
  3. Появляется ли запись в /admin и доходит ли до статуса «готово».
  4. Собирается ли отчёт за день и открываются ли аудио из выгруженного CSV.

Если сеть изолирована

Если сервер не виден с чужого устройства, чаще всего дело в изоляции клиентов на точке доступа. Она включена почти на всех гостевых и корпоративных Wi-Fi.

Изоляция клиентов (client isolation, AP isolation) разрешает устройствам ходить в интернет, но запрещает видеть друг друга внутри сети. Пинг и открытие страницы сервера при этом не работают, хотя оба устройства «в одном Wi-Fi». Лечится это не настройками сервиса, а тем, что сеть поднимается своя.

Как отличить изоляцию от других проблем

С чужого устройства в той же сети выполните ping <IP сервера>. Пинг не проходит, а интернет работает — это изоляция клиентов. Пинг проходит, а страница не открывается — дело в брандмауэре на сервере (см. врезку выше) либо в том, что uvicorn слушает 127.0.0.1 вместо 0.0.0.0.

Если сеть поднять не удалось

Если сеть поднять не удалось совсем — запись всё равно не теряется: она лежит в браузере студента, страница держит её в памяти и предупреждает при попытке закрыть вкладку. При обрыве связи отправка сама повторяется четыре раза с нарастающей паузой, дальше остаётся кнопка «Отправить ещё раз». Достаточно поднять сеть и нажать её.

Как считаются метрики речи

Расчёт опирается на таймкоды отдельных слов, которые Whisper возвращает при word_timestamps=True. Без них доступно только число слов.

  • Пауза — промежуток между соседними словами от PAUSE_MIN_SECONDS (0,3 с). Более короткие — естественные стыки.
  • Длинная пауза — от LONG_PAUSE_SECONDS (2 с).
  • Время речи — длительность минус паузы. Тишина до первого и после последнего слова не входит ни во время речи, ни в статистику пауз.
  • Темп — слова, делённые на время речи, а не на всю запись: иначе обдумывание занижало бы темп говорящего.

Какие слова считаются паразитами

Словарь лежит в config/fillers.txt — одна позиция на строку, строки с # игнорируются. Правится без изменения кода, перечитывается при перезапуске. Сейчас в нём 27 позиций.

Звуки-заполнители · 6

эмээмм ааэээммм

Отдельные слова · 10

нувоттипа корочезначитблин прямпоходуваще допустим

Словосочетания · 11

как быв общемто есть так сказатьэто самоескажем так на самом делев принципечестно говоря как сказатьсобственно говоря

Поиск идёт по границам слов, с приоритетом длинных фраз: «как бы» считается одним паразитом, а не двумя словами, «нуждается» за «ну» не принимается, регистр и «ё/е» роли не играют. В CSV попадает и общее число, и разбивка вида ну: 3, как бы: 1.

Ограничения счётчика

Часть этих слов бывает полноценными членами предложения — «то есть», «значит», «в принципе» в осмысленной фразе паразитами не являются, и счётчик их не различает. Кроме того, Whisper склонен «причёсывать» речь и часть заполнителей теряет: «ну» нередко распознаётся как «но». Модели передаётся подсказка на дословность (WHISPER_INITIAL_PROMPT), но полной дословности не даст ни один движок. Метрику стоит читать как сравнительную оценку, а не как протокол; аудио лежит в той же строке CSV.

Конфиденциальность: что уходит наружу

При настройках по умолчанию (ASR_BACKEND=local) — ни аудио, ни расшифровки, ни ID никуда не передаются. Запись приходит с браузера на сервер, там же распознаётся и там же остаётся. Аналитики, телеметрии, внешних CDN и шрифтов в страницах нет: браузер обращается только к своему же серверу.

Это проверено замером, а не только чтением кода: во время полного цикла (приём записи → загрузка модели → распознавание → метрики) у процесса сервиса не открывается ни одного внешнего сетевого соединения.

Обращение в сеть при старте

При старте библиотека модели спрашивает у huggingface.co, не обновилась ли модель. В этом запросе нет ни аудио, ни текста, ни ID. Убирается строкой в .env — добавлять её нужно после того, как модель один раз скачана:

.env · полностью автономный режим
HF_HUB_OFFLINE=1

После этого сервис не выходит в сеть вообще — можно работать в аудитории без интернета и убедиться в этом, отключив сеть на сервере.

Режим, в котором данные уходят

ASR_BACKEND=openai: каждый аудиофайл отправляется на серверы OpenAI для распознавания. Режим выключен по умолчанию и включается только вручную. Если требование конфиденциальности жёсткое — не включать.

Фамилии не собираются — только четырёхзначный ID, поэтому файлы сами по себе не содержат прямых персональных данных: сопоставление «ID → студент» остаётся у заказчика. Удаление: кнопка в панели убирает запись вместе с файлом, полное стирание — удаление каталога data/.

Почему дробные числа выводятся через запятую

Русский Excel принимает 1.27 за дату и показывает «янв.27». Поэтому при разделителе столбцов ; дробная часть отделяется запятой. При CSV_DELIMITER=, разделителем автоматически становится точка — конфликта не возникает.

Распознавание в тестах подменено заглушкой, поэтому прогон занимает меньше секунды и не требует модели. Покрыто:

  • расчёт пауз, времени речи, темпа и паразитов, включая словосочетания и границы слов;
  • полный путь: приём записи → обработка → появление текста и метрик → CSV;
  • формат дробных чисел для Excel и относительные ссылки внутри отчёта;
  • сборка отчёта за день, его пересборка и архив;
  • проверка ID из четырёх цифр, пустого файла и превышения лимита;
  • поведение при битом аудио — запись не теряется, а получает статус error;
  • код доступа: заголовком и параметром, отказ при неверном.

Известные ограничения

  • Микрофон требует https по сети. Обходится ./run.sh --https; сертификат самоподписанный, предупреждение браузера принимается один раз на устройство.
  • Дословность расшифровки не гарантирована. Whisper нормализует речь; счётчик паразитов — оценка, а не протокол.
  • Одна попытка на ответ. Прослушивания и перезаписи нет по требованию заказчика. Отправка при этом повторяется автоматически, а вкладка предупреждает о закрытии с неотправленной записью.
  • Сертификат привязан к IP. При смене сети удалить certs/ и запустить снова.
  • На Windows брандмауэр нужно разрешить явно. Отклонённый запрос выглядит как проблема сети и сбивает с толку при диагностике.
  • Очередь однопоточная по умолчанию. При большой группе последние расшифровки появятся с задержкой; это не мешает ни записи, ни сдаче ответов.

Что можно доработать

  • QR-код с адресом в панели — чтобы 40 человек не набирали IP руками.
  • Офлайн-очередь на стороне браузера: запись копится в IndexedDB и досылается сама, когда сеть вернётся.
  • Сопоставление ID со списком группы на стороне заказчика, если понадобится выгрузка с фамилиями.
